
# 8. Model Card

## Intended Use

The purpose of this model is to classify Fashion-MNIST grayscale images
into one of ten predefined clothing categories.

The model is intended for:

- Educational demonstrations of image classification.
- Comparing baseline and convolutional neural network architectures.
- Studying model evaluation, error analysis, and Green AI concepts.
- Reproducible machine learning experiments.

## Out-of-Scope Uses

This model is not intended for:

- Medical image analysis.
- OCR applications.
- Industrial inspection systems.
- Surveillance systems.
- Safety-critical decision making.
- Real-world clothing recognition applications.

Performance on Fashion-MNIST should not be interpreted as evidence of
readiness for deployment in these domains.

## Dataset

The model was trained and evaluated using the Fashion-MNIST dataset.

Dataset characteristics:

- 70,000 grayscale images.
- Resolution: 28 × 28 pixels.
- 10 clothing categories.
- 60,000 training images.
- 10,000 testing images.
